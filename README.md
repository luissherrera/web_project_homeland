# De patria a patria

Proyecto web responsivo desarrollado como parte del Sprint 5 de TripleTen.

## Descripción

Este proyecto presenta diferentes lugares de origen de personas de la comunidad TripleTen. La página está diseñada para adaptarse a diferentes tamaños de pantalla, incluyendo dispositivos móviles, tabletas y computadoras.

## Tecnologías utilizadas

- HTML5
- CSS3
- Metodología BEM
- Flexbox
- CSS Grid
- Media Queries
- Diseño responsivo

## Resoluciones principales

El proyecto fue diseñado teniendo en cuenta:

- 320px
- 768px
- 1280px
